# Lineage 2 Summoner Auto-Farming Bot (LU4 Edition)

Высокоскоростной, полностью асинхронный робот-помощник для автоматизации фарма на классе Суммонер в Lineage 2. Проект сочетает технологии компьютерного зрения (Computer Vision) для анализа ситуации на экране и физическую эмуляцию ввода через аппаратную платформу **Arduino Leonardo**, что делает его полностью невидимым для внутриигровых защит.

## 🚀 Основные особенности

* **Асинхронное ядро (`asyncio`):** Все подсистемы (захват экрана, логика боя, общение с COM-портом) работают параллельно. Тяжелые операции OpenCV вынесены в фоновые потоки, что полностью исключает микро-фризы.
* **Аппаратный ввод (Arduino Leonardo):** Бот не использует программную эмуляцию нажатий (типа `pyautogui`). Команды отправляются по COM-порту на плату Arduino, которая определяется операционной системой как реальная USB-клавиатура.
* **Умное зрение (DPI Aware):** Обход системного масштабирования Windows (125%, 150%). Бот сканирует физические пиксели матрицы 1 в 1 в оперативной памяти (без сохранения дебаг-файлов на SSD).
* **Тактическая логика Суммонера:** 
  * Защита от спойл-хантинга (бот пропускает раненых мобов, если их бьет кто-то другой).
  * Защита от потери таргета (если спот пустой, бот проверяет раненую цель в течение 3 секунд; если её ХП стабильно — забирает себе).
  * Автоматический пропуск Боссов (Template Matching иконки черепа в рамке таргета).
  * Мгновенный сбор лута (F1) в 5 потоков сразу после смерти моба.
* **Менеджер Двух Окон:** Бот умеет автоматически находить в Windows и выводить на передний план нужные окна игры по никнеймам персонажей (`LU4 - UnReviver`, `LU4 - Acylut`).
* **Глобальная Пауза:** Нажатие английской клавиши `P` в любом месте системы мгновенно замораживает/возобновляет работу боевого цикла, при этом зрение продолжает бесшумно мониторить экран.

```text
L2_Lu4_Miny_Fighter_bot__3/
├── config.json                     # Конфигурация портов, кнопок, окон и координат калибровки
├── main.py                         # Чистая точка входа для запуска бота

├── arduino/
│   ├── arduino_controller_async.py # Класс взаимодействия с COM-портом платы (aioserial)
│   └── sketch.ino                  # Скетч для загрузки в саму плату Arduino Leonardo
└── vision/
    ├── bot_manager.py              # Центральный менеджер: управление окнами, хоткеи, оркестрация
    ├── screen_capture.py           # Стабильный полноэкранный захват пикселей и Tkinter-калибровка
    ├── hp_tracker.py               # Математический анализ полосы ХП моба по 5 точкам справа налево
    ├── target_validator.py         # Модуль OpenCV для детекции иконки черепа босса
    └── skull.png                   # Шаблон иконки черепа для поиска боссов
```

## 🛠 Установка и настройка

### 1. Подготовка Arduino
1. Подключите **Arduino Leonardo** (на чипе ATmega32U4) к компьютеру.
2. Откройте Arduino IDE, скопируйте код из `arduino/sketch.ino` и загрузите его в плату.
3. Откройте Диспетчер устройств Windows и посмотрите номер порта (например, `COM4`).

### 2. Установка окружения Python
Убедитесь, что у вас установлен Python 3.10+. Откройте терминал в папке проекта и выполните команду:

```bash
pip install -r requirements.txt
```

### 3. Настройка `config.json`
Откройте файл `config.json` в корне проекта и укажите ваш COM-порт, скорость (`115200`), никнеймы основного персонажа и баффера:

```json
{
    "connection": {
        "port": "COM4",
        "baudrate": 115200,
        "dtr": true,
        "rts": true
    },
    "game_windows": {
        "Main_Window": "UnReviver",
        "Second_Window": "Acylut"
    },
    "buttons": {
        "F1": "A", "F2": "B", "F4": "D", "1": "c", "Esc": "X"
    }
}
```

## ⌨️ Маппинг игровых клавиш в Lineage 2

Чтобы бот корректно управлял персонажем, настройте внутриигровые панели макросов под следующие кнопки:
* **`F2`** — Следующая цель (`/nexttarget`)
* **`1`** — Атака слугой (Приказ пету бежать в бой)
* **`F4`** — Атака персонажем (Включение автоатаки хозяина или основной боевой скилл)
* **`F1`** — Подбор лута (`/pickup`)
* **`Esc`** — Сброс текущей цели

## 🏁 Эксплуатация

1. Запустите Lineage 2. Окна должны иметь заголовки вида `LU4 - UnReviver`.
2. Положите скриншот иконки черепа босса в папку `vision/skull.png`.
3. Запустите бота из корня проекта:
   ```bash
   python main.py
   ```
4. **Первый запуск (Калибровка):**
   * Если в конфиге нет координат, бот по очереди откроет два полноэкранных Tkinter-интерфейса.
   * **Шаг 1:** Зажмите ЛКМ в начале красной полосы ХП моба, протяните до конца и отпустите.
   * **Шаг 2:** Зажмите ЛКМ и выделите прямоугольную рамку таргета, где появляется иконка черепа босса.
   * Данные автоматически сохранятся в `config.json`, при повторных запусках калибровка не потребуется.
5. Переключитесь на игру. Бот сам сфокусирует основное окно и начнет асинхронный цикл фарма.
6. В любой момент нажмите английскую клавишу **`P`** для активации глобальной паузы. Повторное нажатие возвращает бота в бой.

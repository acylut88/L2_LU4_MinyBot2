# Lineage 2 Multi-Box Auto-Farming Bot (LU4 Edition)

Высокоскоростной, полностью асинхронный робот-оркестратор для автоматизации игрового процесса в два окна на хрониках Lineage 2 LU4. Спроектирован по модульному паттерну «Стратегия», сочетает в себе технологии компьютерного зрения (Computer Vision) для анализа шкал состояния и физическую эмуляцию аппаратного ввода через микроконтроллер **Arduino Leonardo**, что обеспечивает полную невидимость для внутриигровых античитов.

## 🚀 Основные особенности

* **Параллельная асинхронность (`asyncio`):** Все подсистемы (многопоточный захват экрана, логика боевых профилей, взаимодействие с COM-портом платы, независимые таймеры саппорт-расписаний) работают изолированно. Тяжелые операции OpenCV вынесены в фоновые исполнители, исключая микро-фризы ядра.
* **Аппаратный USB HID-ввод:** Бот не использует программные клики или API-инъекции. Сигналы передаются по COM-порту на Arduino Leonardo со скоростью 115200 бод, которая определяется операционной системой Windows как реальная физическая USB-клавиатура и мышь.
* **Универсальный StateTracker (6 точек контроля):** Интеллектуальный контур анализа пикселей шкал здоровья и маны. Каждая полоса делится на 6 строгих сегментов (0%, 20%, 40%, 60%, 80%, 100%). Внедрен прямой попиксельный RGB-анализ спектра шкал, полностью защищенный от мерцания интерфейса игры, бликов и «рваного» мусора (цифр критов и урона поверх полосы).
* **Интерактивный Setup Wizard:** При запуске бот предлагает выбрать или создать графический профиль. Для нового профиля запускается сквозная калибровка 3 шкал (ХП моба -> ХП мейна -> МП мейна) в 1 пиксель с помощью Tkinter-интерфейса, а также выбор количества окон и персонажей с автоматической защитой от выбора дублирующихся никнеймов.
* **Адаптивный Multi-Box менеджмент (4 роли саппорта):**
  1. **Баффер (Овер/Варк):** Циклический ребафф группы кнопок по таймеру без сбора группы.
  2. **Заливка + Бафф (ЕЕ/ШЕ):** Автоматический сбор группы силами мейна (`F5`), прыжок фокуса окон на саппорта (`VeraWater`), прокаст линейки из 7 баффов (`F1`-`F7`) по таймеру (19 минут), каст заливки маны при падении МП мейна ≤ 20%, автоматический выход из группы (`/leave`) и инерционный бег за основой.
  3. **Заливка:** Прожатие макроса заливки маны строго по требованию мейна при просадке МП, без долгого ребаффа.
  4. **Просто бегать:** Заглушка следования за лидером без активных действий.
* **Устойчивый обход фокус-блокировок Windows:** Корутина `switch_window` защищена от системных ошибок `SetForegroundWindow`. Перед переносом фокуса скрипт сбрасывает таргет, восстанавливает свернутые окна из панели задач и симулирует аппаратное нажатие системной клавиши `ALT` через Win32 API, снимая запрет ОС на перехват окон фоновыми процессами.
* **Боевой профиль Мага-Дварфа:** Реализует агрессивный MVP-цикл (без «вежливого» пропуска раненых мобов). Внедрено жесткое пробивание геодаты: бот циклично спамит маг-скилл (`1`) и физическую атаку сближения (`4`), пока ХП моба не сдвинется с места. Поддерживает добивание рукой на ≤ 20% ХП и гибридный реген маны (сидение на жопе через `Num*` в соло-режиме, либо запрос пати-заливки в режиме Dual-Box).
* **Встроенный дальний маяк (Стягивание):** Если 5 нажатий Next Target (`F2`) завершаются неудачей, бот прожимает макрос дальнего поиска (`0`). При появлении ХП-бара проверяет цель на Босса (иконка черепа через Template Matching OpenCV), инициирует движение, сбрасывает дальний таргет через `Esc` и на бегу перехватывает ближних мобов короткими сериями прожимов `F2`.
* **Глобальный хоткей Паузы:** Нажатие клавиши **`P`** в любой момент времени мгновенно замораживает и размораживает боевой цикл, логи и таймеры ребаффа, переводя бота в безопасный режим мониторинга.

    ├── __init__.py                 # Маркер пакета модулей

## 🛠 Установка и настройка

### 1. Подготовка аппаратной части
1. Подключите **Arduino Leonardo** (на микроконтроллере ATmega32U4) к свободному USB-порту.
2. Прошейте плату скетчем с поддержкой отправки HID-клавиш.
3. Откройте Диспетчер устройств Windows и зафиксируйте выданный номер порта (например, `COM7`).

### 2. Развертывание окружения Python
Откройте консоль/терминал в корневой директории проекта и выполните команду для установки зависимостей:
```bash
pip install -r requirements.txt
```

### 3. Подготовка клиентов Lineage 2
Запустите игру. Убедитесь, что окна имеют заголовки, строго соответствующие шаблону мастера (например, `LU4 - alise` и `LU4 - VeraWater`). 

Настройте панели быстрого доступа на персонажах:
* **На Мейне (Маг-Гном):**
  * `F2` — Следующая цель (`/nexttarget`)
  * `1` — Магический нюк/заклинание
  * `4` — Физическая атака (сближение/добивание)
  * `0` — Макрос дальнего таргета по имени моба (`/target Имя_Мобы`)
  * `F5` — Макрос приглашения саппорта в группу:
    ```text
    /target VeraWater
    /invite
    ```
  * `Num*` — Стандартное действие «Сесть / Встать» (используется только при соло-фарме).
* **На Саппорте (ЕЕ `VeraWater`):**
  * Панель баффов от `F1` до `F7`. На клавишу `F1` первой строчкой пропишите команду автоматического принятия группы `/rejoin`. На клавишу `F7` (последний бафф) настройте макрос:
    ```text
    /useskill [Название 7-го баффа]
    /delay 2
    /leave
    /target alise
    /attack
    ```
  * На кнопку **минус `"-"`** вынесите макрос пати-заливки маны:
    ```text
    /rejoin
    /target alise
    /useskill Recharge
    /delay 2
    /leave
    ```

## 🏁 Эксплуатация

1. Запустите бота из корня проекта:
   ```bash
   python main.py
   ```
2. Следуйте инструкциям пошагового интерактивного меню в консоли. При выборе создания нового профиля проведите аккуратные линии мыши слева направо по трем шкалам в игре.
3. По окончании настройки окон бот автоматически привяжет HWND дескрипторы, проверит статус Arduino, совершит принудительный стартовый пати-ребафф и введет гнома в циклическую охоту.
4. Для визуального контроля и проверки точности попадания контрольных точек в шкал-бары используйте изолированный инструмент дебага:
   ```bash
   python tests/test_vision.py
   ```
   Он раз в секунду обновляет файл `debug_scan.png` в корне проекта, подсвечивая заполненные точки зеленым, а пустые — красным цветом.
5. Нажмите английскую клавишу **`P`** в любой момент для экстренной остановки/запуска бота.

# Lineage 2 Summoner Auto-Farming Bot (LU4 Edition)

Высокоскоростной, полностью асинхронный робот-помощник для автоматизации фарма на классе Суммонер в Lineage 2. Проект сочетает технологии компьютерного зрения (Computer Vision) для анализа ситуации на экране и физическую эмуляцию ввода через аппаратную платформу **Arduino Leonardo**, что делает его полностью невидимым для внутриигровых защит.

## 🚀 Основные особенности

* **Асинхронное ядро (`asyncio`):** Все подсистемы (захват экрана, логика боя, общение с COM-портом, независимые таймеры баффов) работают параллельно. Тяжелые операции OpenCV вынесены в фоновые потоки через исполнителей, что полностью исключает микро-фризы.
* **Аппаратный ввод (Arduino Leonardo):** Бот не использует программную эмуляцию нажатий. Команды отправляются по COM-порту на плату Arduino, которая определяется операционной системой как реальная USB-клавиатура.
* **Настоящий Keypad-Нампад:** В скетче задействованы нативные аппаратные USB HID константы (`KEY_KP_1` – `KEY_KP_9`), что позволяет использовать боковую цифровую панель для баффов независимо от текущей раскладки Windows (RU/EN).
* **Умное зрение (DPI Aware):** Обход системного масштабирования Windows (125%, 150%). Бот сканирует физические пиксели матрицы 1 в 1 в оперативной памяти (без сохранения дебаг-файлов на SSD для максимальной скорости).
* **Монолитная валидация ХП:** Математический анализ полосы ХП моба по 5 контрольным точкам справа налево. Рваные кадры из-за пролетающих цифр урона и критов (например, `['-', '-', '+', '-', '-']`) аппаратно отфильтровываются и игнорируются, исключая ложные скачки.
* **Тактическая логика и вежливый фарм:** 
  * Первый раненый моб летит в пропуск через Next Target (`F2`). На втором — бот замирает на 2 секунды. Если за это время его ХП стабильно (никто чужой не бьет) — забирает цель себе.
  * Автоматический пропуск Боссов (порог OpenCV для иконки черепа выставлен на чувствительные `0.68`). При обнаружении босса бот мгновенно прожимает `Esc`, обрывая петлю захвата.
  * Атомарный сбор лута: цикл сбора на `F1` заперт внутри фазы смерти моба. Бот гарантированно подбирает весь дроп и только потом размораживает поток для поиска следующей цели.
* **Интеллектуальное стягивание (Long-Range Pulling):** Если ближний Next Target (`F2`) выдает 5 фейлов подряд, активируется контр-фича простоя. Бот жмет макрос поиска по имени (`"0"`), асинхронно сканирует появление ХП-бара (15 проверок по 100 мс), дает команду атаки, а затем жестко сбрасывает таргет спамом `Esc` (3 раза через 0.3 сек). Персонаж движется к споту по инерции, на бегу перехватывая ближних мобов через `F2` каждые 0.5 сек.
* **Синхронизированный ребафф:** Таймеры `Num1-Num9` тикают в фоне, но прожимаются строго на Шаге 1 боевого цикла, когда моб умер и лут собран. Каст блокирует боевой цикл (пауза 2.0 сек на бафф), исключая срывы заклинаний во время драки.
* **Менеджер Двух Окон:** Бот умеет автоматически находить в Windows и выводить на передний план нужные окна игры по никнеймам персонажей (`LU4 - UnReviver`, `LU4 - Acylut` через дескрипторы `win32gui`).
* **Глобальная Пауза:** Нажатие английской клавиши `P` в любом месте системы мгновенно замораживает/возобновляет работу боевого цикла и баффера, при этом зрение продолжает бесшумно мониторить экран.

## 🛠 Установка и настройка

### 1. Подготовка Arduino
1. Подключите **Arduino Leonardo** (на чипе ATmega32U4) к компьютеру.
2. Откройте Arduino IDE, скопируйте обновленный код с поддержкой констант `KEY_KP_X` и загрузите его в плату.
3. Откройте Диспетчер устройств Windows и посмотрите номер порта (например, `COM4`).

### 2. Установка окружения Python
Убедитесь, что у вас установлен Python 3.10+. Откройте терминал в папке проекта и выполните команду:

```bash
pip install -r requirements.txt
```

### 3. Настройка `config.json`
Откройте файл `config.json` в корне проекта и укажите ваш COM-порт, скорость (`115200`), никнеймы основного персонажа и баффера:

```json
{
    "connection": {
        "port": "COM4",
        "baudrate": 115200,
        "dtr": true,
        "rts": true
    },
    "game_windows": {
        "Main_Window": "UnReviver",
        "Second_Window": "Acylut"
    },
    "buttons": {
        "F1": "A", "F2": "B", "F4": "D", "1": "c", "Esc": "X", "0": "l",
        "Num1": "o", "Num2": "p", "Num3": "q", "Num4": "r", "Num5": "s", 
        "Num6": "t", "Num7": "u", "Num8": "v", "Num9": "w"
    }
}
```

## ⌨️ Маппинг игровых клавиш в Lineage 2

Чтобы бот корректно управлял персонажем, настройте внутриигровые панели макросов под следующие кнопки:
* **`F2`** — Следующая цель (`/nexttarget`)
* **`1`** — Атака слугой (Приказ пету бежать в бой)
* **`F4`** — Атака персонажем (Включение автоатаки хозяина или боевой скилл)
* **`F1`** — Подбор лута (`/pickup`)
* **`Esc`** — Сброс текущей цели
* **`0`** — Дальний макрос таргета по имени моба (`/target Имя_Мобы`)
* **`Num1 - Num9`** — Баффы Варка/Овера, выведенные на боковую Нампад-панель игры

## 🏁 Эксплуатация

1. Запустите Lineage 2. Окна должны иметь заголовки вида `LU4 - UnReviver`.
2. Положите скриншот иконки черепа босса в папку `vision/skull.png`.
3. Запустите бота из корня проекта:
   ```bash
   python main.py
   ```
4. Для проверки разметки ХП-бара без запуска Ардуино используйте тестовый модуль:
   ```bash
   python tests/test_vision.py
   ```
   Он будет генерировать дебаг-файл `debug_scan.png` в корне проекта, подсвечивая точки контроля.
5. В любой момент нажмите английскую клавишу **`P`** для активации глобальной паузы. Повторное нажатие возвращает бота в бой.
